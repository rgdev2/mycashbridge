# CashBridge.com — Project Source

A multi-page loan-marketplace (LSP/DSA) website for an Indian audience. Plain HTML + CSS + vanilla JS — no build step, no framework. Open in VS Code and edit directly.

## Run locally
Because pages share `assets/site.js` and `assets/site.css`, open via a tiny local server (not `file://`):

```
# from the project root, pick one:
python3 -m http.server 8080
# or
npx serve .
```
Then visit `http://localhost:8080/index.html`.

## Where things live (important!)
The nav bar, mobile drawer, footer, floating call/WhatsApp buttons, the "Apply" modal,
the cookie-consent banner, the EMI calculator logic, and the English/Hindi engine are all
**generated by `assets/site.js`** and injected into every page at these mount points:

```html
<div data-mount="nav" data-current="loans"></div>   <!-- nav injected here -->
<div data-mount="footer"></div>                       <!-- footer injected here -->
```

So to edit shared chrome, edit `assets/site.js` (not each HTML file). Key spots in `site.js`:
- `CFG`            — brand name, lead email, phone, WhatsApp, tagline, thank-you text
- `LOANS / CARDS / INSURANCE / INVEST / TOOLS` — nav menu items
- `navHTML / drawerHTML / footerHTML` — markup for nav, drawer, footer
- `formFieldsHTML / thanksHTML` — the apply form + thank-you animation
- `sendLead`       — where the form POSTs leads (FormSubmit → your email)
- `HI = { ... }`   — the curated English→Hindi dictionary (add/edit translations here)
- `autoTranslate`  — runtime Hindi fallback (uses an LLM API only in the build environment)

Page-unique content (hero copy, benefits, eligibility, FAQs, rate tables, article text)
lives directly in each HTML file, so you can edit those inline.

## Forms / leads
Forms submit to the email in `CFG.leadEmail` via FormSubmit. On first real submission from
your live domain you must click the one-time activation link FormSubmit emails you.
Until hosted, the thank-you animation still plays but no email is sent.

## Before going live (replace placeholders)
- Company legal name, CIN, GSTIN, registered address, grievance-officer details (footer + policy pages)
- Phone / WhatsApp numbers (`CFG.phone`, `CFG.phoneRaw`, `CFG.whatsapp`)
- Have the legal/policy pages reviewed by counsel; have Hindi legal copy professionally translated
- Confirm HDFC logo usage and indicative rates match your actual partner agreements

## Notes
- Icons: Lucide (loaded from CDN). Fonts: Manrope/Lora via the design-system CSS.
- Language choice, cookie consent, and hero choice persist in `localStorage`.
- The Hindi auto-translation of long body text needs the build environment's API; the
  curated dictionary covers the core funnel offline. For production, bake static Hindi
  into the pages you care about.
